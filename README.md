# 📱 3D iPhone Website

🚀 A high-performance, interactive 3D iPhone showcase built with **React, Three.js, GSAP, and TailwindCSS**.

## 🛠 Tech Stack

- **JavaScript, React, THREE.js, GSAP** – for interactive 3D rendering.
- **ESLint, TailwindCSS** – for optimized styling and clean code.
- **VS Code** – Development environment.

## ✨ Features

### ⚡ Performance
- Achieved **90+ Lighthouse score** with optimized **3D rendering**.
- **Reduced load time by 40%** through efficient asset management.

### 🎨 Technical
- Implemented **custom Three.js shaders** for **30% better performance** than traditional WebGL approaches.

### 📱 Responsive
- Created adaptive **3D scenes** that **reduce memory usage by 50%** on mobile devices.

## 🚀 Setup & Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/3d-iphone-website.git

# Navigate to project directory
cd 3d-iphone-website

# Install dependencies
yarn install  # or npm install

# Start development server
yarn dev  # or npm run dev
```
